# Práticas de Programação e Estruturas de Dados

Repositório contendo exercícios práticos, algoritmos e projetos de estudo desenvolvidos em Engenharia de Software.

## 📁 Estrutura do Repositório

- **`c/`**: Algoritmos em C, estruturas de dados (`struct`) e manipulação de arquivos/dados.
- **`python/`**: Scripts em Python abordando lógica de programação, condicionais, repetições, manipulação de strings e funções utilitárias.

## 🛠️ Tecnologias Utilizadas
- C (GCC)
- Python 3
